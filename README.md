# Product Analytics SQL Portfolio
This repository contains SQL-based product and business analytics projects using an ecommerce retail dataset.

The projects focus on:
- customer retention
- revenue analytics
- cohort analysis
- product performance
- business recommendations

Tools used:
- SQLite
- SQL
- Tableau / Excel
- GitHub

- Dataset:
Online Retail transactional dataset from Kaggle containing:
- invoices
- products
- customers
- countries
- transaction timestamps

- ## Projects

### 1. Customer Retention Analysis
Goal:
Analyze repeat purchase behavior and identify loyal customers.

Key Insights:
- 65% of customers only purchased once
- repeat customers generated 78% of revenue

Skills:
- CTEs
- window functions
- aggregation
- customer segmentation
